# Results

| Folder or file | What |
| --- | --- |
| `study4/` | The final study: the simple model (ordered logit, this folder), the tuned networks (`neural/` per meeting, `neural_t1/` monthly), the sensitivity checks and the pooled news test. Its README lists every file and its status |
| `inputs_from_earlier/` | Two input files copied from earlier designs (Haiku memory exam, untuned paper-settings forecasts) |
| `stance_accuracy.csv` | Held-out accuracy of the per-year ChronoBERT stance classifiers |
| `coverage.csv`, `dropped_docs.json` | Fed document corpus coverage by year and type, and documents dropped while building it |
| `pip_freeze.txt` | Exact Python package versions |
